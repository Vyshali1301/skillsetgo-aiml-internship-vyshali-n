# Task 3.3 - Prompt Engineering Portfolio

## Objective

Design and test LLM prompts for reasoning, extraction, summarization, and coding.

## Tools Used

- ChatGPT (OpenAI)

## Work Completed

1. Designed and tested a first-attempt prompt for a reasoning task and evaluated the quality of the response.
2. Improved the reasoning prompt by adding step-by-step instructions and compared the results.
3. Designed and tested an extraction prompt and improved it by specifying the required information and output format.
4. Designed and tested a summarization prompt and improved it by specifying the length, audience, format, and important points to retain.
5. Designed and tested a coding prompt and improved it by specifying the programming language, constraints, edge cases, test cases, and time complexity.
6. Documented the prompts, output summaries, improvements, and techniques used in `Prompt-Evaluation-Sheet.md`.
7. Wrote an overall reflection on the prompting techniques that produced the biggest improvements.

## Deliverables

- `Prompt-Evaluation-Sheet.md` - The completed evaluation sheet containing prompts, output summaries, notes, improvement techniques, and reflection.

## Key Learnings

- Specific and detailed prompts generally produce clearer and more useful results than vague prompts.
- Defining the required output format helps the LLM provide more organized and consistent responses.
- Adding constraints and edge-case requirements improves the quality of coding responses.
- Breaking complex tasks into smaller steps helps improve reasoning and makes answers easier to verify.
- When a prompt does not produce the desired result, identifying the missing requirement and adding it to the prompt is an effective way to improve the output.
